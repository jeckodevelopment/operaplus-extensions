# Opera+ Image Optimizer — 1.1.1

Enable **Media Action – Opera+ Image Optimizer** after installing. New local-images Media Manager JPEG/PNG uploads only; quality 90, maximum long edge 1920 px, no enlargement, exclude images/logos and images/branding (including descendants). Successful conversion saves only a smaller WebP with a readable stem and random suffix; Joomla returns its filename. No frontend assets or database rewrites. Existing files, explicit overrides, remote adapters, GIF, SVG, WebP, animated PNG and unsupported formats remain untouched. GD WebP and EXIF required for JPEG; EXIF orientation and PNG alpha handled. Invalid input, missing engine, insufficient memory or larger output: leave original to native validation. Limits: 20 MiB, 12 MP, 10000 per axis. GD strips metadata/ICC; exclude archival/colour-critical images. Joomla must allow input and WebP types. No retention archive, Imagick, GIF conversion, responsive variants or mass migration yet. Preserve source photographs externally.

Manual acceptance: upload JPEG and PNG via Media Manager and article picker, verify returned path, dimensions, alpha, orientation, exclusions, duplicate names, existing files unchanged, disabling plugin and GIF. Re-upload existing heavy editorial cover as a new upload, select returned WebP in article, retain referenced old file. Retest Lighthouse same page/profile. No stable publication or production deployment without approval.

## Upload feedback and diagnosis

The cumulative package also installs System – Opera+ Image Optimizer feedback, automatically enabled on first install; keep it enabled. It only loads a script in Media Manager when the optimizer is enabled and the user has upload permission. Every successful native file upload reports conversion and size savings or the reason the original format was retained. Native upload failures remain handled by Joomla. A warning is displayed if the server returns no optimizer result. Reasons include adapter, exclusions, filename, overwrite, format settings, Media allowed extensions/MIME, GD WebP, EXIF, memory, input size, invalid image, dimensions, animated PNG, encoder, and WebP not smaller. Joomla log path contains operaplus-imageoptimizer.php with reason codes (no file names). Existing files and their URLs remain unchanged; an explicit overwrite retains its original extension. Actual staging issue #18 is not considered resolved until a new upload and feedback have been verified.
