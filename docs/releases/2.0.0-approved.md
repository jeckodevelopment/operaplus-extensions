# Opera+ Extensions 2.0.0

Introduzione di Opera+ Gallery: caricamento multiplo, ottimizzazione WebP, gestione editoriale, griglia responsive e lightbox, crediti e didascalie, revisioni e manutenzione delle bozze temporanee.

- Anteprime senza sfondo grigio e indicazione dinamica del peso massimo di ogni fotografia.
- Aggiornamento cumulativo per Joomla 6, con rigenerazione della mappa delle namespace delle estensioni dopo l'installazione.
- Entrambi i plugin della galleria sono opt-in; abilitarli per utilizzare la funzione.
