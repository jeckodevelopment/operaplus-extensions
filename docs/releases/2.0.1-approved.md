# Opera+ Extensions 2.0.1

Aggiornamento correttivo della galleria fotografica Opera+:
- Anteprime pubbliche uniformi in formato 4:3, ritaglio centrato senza deformazioni e senza modifiche ai file WebP esistenti.
- Gallerie centrate orizzontalmente, anche nelle righe incomplete, su desktop, tablet e smartphone.
- Anteprime omogenee anche nell'editor; fotografie intere nel lightbox.
- 45 combinazioni di test grafici e test di integrazione Joomla con immagini di proporzioni diverse.

Pubblicazione autorizzata il 28 novembre 2026 per aggiornamento nativo Joomla. GAL-T01–T04 superati sulla 2.0.0; GAL-T05–T09 e verifica delle correzioni 2.0.1 restano da eseguire. Tutti i controlli automatici della modifica e di main sono superati. La pubblicazione resta subordinata al superamento dei controlli della pipeline di release. Eseguire un backup prima dell'aggiornamento.
