# Opera+ Extensions 1.0.0

First stable release for Joomla 6 and PHP 8.3 or later. Includes the shared Atlas library, contextual Atlas module and article association field, configurable CTA module and six editorial templates for TinyMCE.

- Native installation, upgrade from 0.3.3, field persistence, access and publication restrictions, web installer and responsive visual regression tests passed on the release candidate (PR #13).
- User confirmed successful installation of the 1.0.0 candidate on 25 November 2026. Module design and the Verdi portrait without visible Public Domain credits had been approved previously.
- Install the cumulative package without extracting it; existing package-managed installations can update in place. The stable update feed is included with the release.

See README.md and docs/RELEASE.md for installation and update details.
