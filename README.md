# Opera+ Extensions

Joomla 6 extensions for the Opera+ magazine. Development milestone 1.0.0: see [roadmap](https://github.com/jeckodevelopment/operaplus-extensions/issues/1). No stable release yet.

## Preview 0.1.0

- Library, Atlas module and article field: [Atlas integration](docs/ATLAS.md).
- Configurable CTA and editorial templates: [Editorial extensions](docs/EDITORIAL.md).

CI builds five individual ZIP packages. This is a development preview, not a stable release. Install only on a Joomla 6 test instance.
