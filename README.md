# Opera+ Extensions

Joomla 6 extensions for the Opera+ magazine. Development milestone 1.0.0: see [roadmap](https://github.com/jeckodevelopment/operaplus-extensions/issues/1). Stable release publication is tracked on the [Releases page](https://github.com/jeckodevelopment/operaplus-extensions/releases).

## 1.0.0

- Library, Atlas module and article field: [Atlas integration](docs/ATLAS.md).
- Configurable CTA and editorial templates: [Editorial extensions](docs/EDITORIAL.md).

CI builds five individual ZIP packages and one cumulative package. See [release and updates](docs/RELEASE.md). Use the cumulative package from the Releases page for normal installations. CI artifacts are for development testing.
